# 01 · Research Goal

## 北极星(一句话)

在语言模型中检验「diffusion 与 autoregression 是同一套内核在不同基函数空间中的展开」这一假设——
不是在分布层面(已知 masked diffusion ≡ any-order AR),而是在**机制 / 表征层面**:
训练好的 DLM 与 AR LLM 是否学到了可经一个**显式换基算子**相互对齐的同一内部内核;
并据此探索一个直接推论——是否存在一组让 probability-flow ODE 路径接近直线的"好基",
从而显著提升训练 / 采样效率。

## 可操作化的 hypothesis

> 把"同一内核、不同基"变成可测命题。

存在一个换基算子 `T`,使得在**匹配的生成轨迹**上,AR 模型的隐表征与 DLM 的隐表征近似满足

```
h_AR  ≈  T( h_DLM )
```

- 若 `T` 可取**线性 / 正交**(低秩、低重建误差)→ 支持"强版本":两者是同一内核的线性换基。
- 若 `T` 必须**高度非线性**才能对齐 → "基"框架被证伪为过弱,需退回到更弱的"信息等价"陈述。

**线性 vs 非线性的分叉本身就是核心可交付的发现。**

## 三个可证伪的研究问题

### RQ1 — 分布层面对齐(地基)

在同一组 partial-masking 条件下,训练好的 DLM 与 AR 给出的条件分布有多接近?
用预测分布的 agreement / KL 量化。检验"内核"在功能层面是否真的同一,而非仅理论上等价。

### RQ2 — 机制层面换基(核心)

是否存在低秩 / 正交的 `T`,沿生成轨迹稳定地对齐两者表征?
- AR 的轨迹轴 = position / order;DLM 的轨迹轴 = denoising-time。
- 用 **Procrustes / CKA + crosscoder**(共享特征 vs 模型特有特征的占比)量化"共享内核"的比例。
- 定位"基"差异具体落在哪些层 / 哪种结构上(已知 diffusion 早层冗余多、recency bias 弱)。

### RQ3 — 邪修推论(探索)

把前向过程 / interpolant / latent 基**参数化为可学**,
在"重建共享内核"与"PF-ODE 路径直度(NFE / 曲率最小)"的**联合目标**下优化——
是否存在一个基,使内核低复杂度 **且** 路径近直,从而少步 marching?
关键:检验这两者能否在**同一个基**里兼得(已有工作分头攻基与直度,联合是空白)。

## Scope 与定义

把"基"说清楚,避免它做无承载的隐喻。

- **模型对**:LLaDA / Dream(DLM)对 LLaMA 量级 AR;优先包含
  - 一对**同源**(AR 初始化再 diffusion 训练)——隔离 initialization bias;
  - 一对**独立训练**——隔离目标函数本身的效应。
- **"基"的两层含义需分别处理**:
  - 语言上的精确版本 = **因子化顺序(order)**;
  - 连续 / 可微版本 = RQ3 中**学到的 embedding / latent 基**。
- RQ3 的 ODE flow marching **只在连续 latent 上字面成立**;离散 token 需经显式连续松弛——
  这是该 RQ 的已知前提与风险。

## 成功 / 证伪判据

| 结果 | 判据 |
|---|---|
| **强成功** | RQ2 中一个低秩正交 `T` 即可在多层、多轨迹位置稳定对齐(共享比例高);RQ3 找到的可学基在固定质量下显著降低 NFE / 训练步数 |
| **部分成功** | 对齐需分层非线性 `T`,但共享子空间显著且可解释 → "同一内核"成立但"换基"非线性 |
| **证伪** | 无任何低维 `T` 能对齐,共享子空间不显著 → DLM 与 AR 机制上是不同内核,假设被否定 |
