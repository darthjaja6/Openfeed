# Goal

> 执行摘要版的研究目标。详细的可操作化定义、研究问题与判据见 `01-goal.md`;
> 方法见 `03-methodology.md`;第一步代码见 `code/`。

## 一句话目标

**判定 diffusion 与 autoregressive 语言模型是否在不同的"基"下实现了同一套内核——
并把"基"从一个隐喻变成一个可测量、可优化的对象,进而探索一个能加速生成的"好基"。**

## 背景定位:我们补的是哪一格

在**分布层面**,这件事已经是定理:masked / absorbing diffusion 等价于 any-order
autoregression(同一套条件分布,不同的因子化顺序)。已有的表征对比工作则显示两种范式
学到的内部结构"有意义地不同"。

二者之间留下一个**没人正面回答的问题**:训练好的 DLM 与 AR,在**机制 / 表征层面**,
是否是同一内核经过一次**可显式写出的换基**而得来——而这个换基是**线性的**(强:同一内核
的旋转),还是必须**高度非线性**(弱:只是信息等价)?这正是本研究的靶心。

## 核心假设(可证伪)

存在换基算子 `T`,在匹配的生成轨迹上使 `h_AR ≈ T(h_DLM)`。
- `T` 可取**线性 / 正交**(低秩、低残差)→ "同一内核、不同基"成立(强版本)。
- `T` 必须**非线性** → "基"框架过弱,退回到信息等价。

**线性 vs 非线性这个分叉本身,就是本研究的主结论。**

## 三个目标(Aims)

1. **Aim 1 — 功能等价性(地基)。** 在相同的 (已揭示上下文, 待预测位置) 条件下,量化 DLM 与
   AR 的**预测分布距离**,并以范式内(AR-vs-AR)距离为基线。回答:它们的"内核"在功能上是否同一。

2. **Aim 2 — 机制换基(核心)。** 用 Procrustes / CKA / rank-distortion 判定 `T` 的复杂度,
   用 crosscoder 把表征分解为**共享内核**与**模型特有(= 基差异)**两部分,定位差异落在哪些层、
   对应什么语言结构。产出 `T` 的复杂度判定 + (层 × 轨迹位置) 的共享比例图。

3. **Aim 3 — 可学基加速(邪修推论)。** 把前向过程 / latent 基**参数化为可学**,在"重建共享内核"
   与"probability-flow ODE 路径直度"的**联合目标**下优化,检验是否存在一个基让内核低复杂度
   *且* 路径近直,从而少步 ODE marching、显著提速。已知瓶颈:直度主要由 coupling 决定,故真正
   的优化对象是 **(基, coupling) 对**——这一联合问题目前无人系统研究。

## 为什么重要 / 新在哪

- **科学上**:把"diffusion 与 AR 是否同一内核"从分布层面的已知定理,推进到**机制层面的可证伪判定**,
  并给出"基"的精确数学刻画(线性/正交 vs 非线性)。
- **方法上**:首次把 SAE 普适性 / crosscoder model-diffing 用于 **DLM↔AR 跨范式**(此前只用于范式内或
  base-vs-finetune),共享部分 = 内核、特有部分 = 基差异,正好对应本假设。
- **应用上**:若 Aim 3 成立,"换一个好基"提供一条**与架构无关的训练 / 采样加速**路径。

## 成功 / 证伪判据(一句话)

- **强成功**:低秩正交 `T` 在多层稳定对齐 + 可学基在固定质量下显著降低 NFE / 训练步数。
- **部分成功**:对齐需非线性 `T`,但共享子空间显著且可解释。
- **证伪**:无任何低维 `T` 能对齐,共享子空间不显著 → DLM 与 AR 机制上是不同内核。
